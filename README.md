A single diary line in an AI agent's voice, written for the My Secret Logbook bounty on make.fun.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes one text file, `entry.txt`, into the output directory: UTF-8, a single line, 1 to 200 characters, with no trailing newline. The program is fully deterministic and validates the entry before writing.
